# GPA Calculator

A simple and interactive web application to calculate Grade Point Average (GPA). Built with **HTML**, **CSS**, and **JavaScript**, this tool allows students to input their courses, grades, and credits to compute their GPA quickly and efficiently.

## ✨ Features
- Add, edit, and delete courses dynamically  
- Input course credits and grades with validation  
- Automatic GPA calculation and real‑time updates  
- Dark/light theme toggle with persistent settings  
- Responsive design for desktop and mobile  
- Local storage support to save user data  

## 📂 Project Structure
```
├── index.html        # Main HTML file
├── css/
│   └── main.css      # Stylesheet for layout and design
├── js/
│   └── main.js       # Core logic and interactivity
```

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/DungTLab/GPA-Calculator.git
   ```
2. Navigate to the project folder:
   ```bash
   cd GPA-Calculator
   ```
3. Open `index.html` in your browser.

### Usage
1. Enter your courses, credits, and grades.  
2. Click **Calculate GPA** to view results.  
3. Use the **Reset** button to clear all data.  
4. Toggle between light/dark themes for better readability.  

## 🛠️ Technologies Used
- **HTML5** for structure  
- **CSS3** for styling and responsive design  
- **JavaScript (ES6)** for GPA calculation logic and UI interactions
